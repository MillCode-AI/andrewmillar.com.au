# andrewmillar.com.au

Static website for Andrew Millar Consulting.

## Structure

- `index.html` - the homepage (single page)
- `assets/css/styles.css` - all styles
- `assets/img/amc-logo.png` - AMC logo used in the header (192px)
- `assets/img/amc-logo-512.png` - AMC logo used for link previews
- `assets/img/andrew-millar.jpg` - photograph for the About section
- `favicon-48.png`, `apple-touch-icon.png` - browser and home-screen icons
- `CNAME` - custom domain for GitHub Pages

No build step, framework or external dependencies. Open `index.html` in a browser to preview.

## Publishing

Hosted as a static site (for example GitHub Pages, serving from the repository root).
Point the `andrewmillar.com.au` DNS records at the host as per the host's custom domain instructions.

## Content rules

This repository is public. Only customer-facing website content belongs here.
